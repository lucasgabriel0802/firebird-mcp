# Perguntas e Respostas — 2026-10-16_configuracao-central-bancos

| ID | Pergunta | Impacto se não clarificado | Status | Data Resposta | Resposta do Stakeholder |
| :--- | :--- | :--- | :--- | :--- | :--- |
| P01 | Como o MCP deve inferir o projeto atual: pelo nome da pasta raiz (`Path.cwd().name`), pelo caminho absoluto ou por um parâmetro opcional informado pelo usuário/IDE? | Se for apenas pelo nome da pasta (`web_projects`), duas pastas com mesmo nome em diretórios diferentes seriam tratadas como o mesmo projeto. | [RESPONDIDA] | 16/10/2026 | Identificar automaticamente pelo nome da pasta atual (`Path.cwd().name`), mantendo a opção de informar o nome do projeto explicitamente caso necessário via parâmetro/ambiente. |
| P02 | Quando o usuário adicionar ou atualizar um novo banco via `fb_configure_database`, o salvamento padrão deve ser no catálogo global central (`~/.firebird-mcp.json`) ou no arquivo local do projeto se existir? | Risco de salvar conexões de projeto no global ou conexões globais no projeto local, gerando inconsistência. | [RESPONDIDA] | 16/10/2026 | Salvar por padrão no Catálogo Global Central (`~/.firebird-mcp.json`), incluindo automaticamente o nome do projeto atual na lista de `"projects"` do banco cadastrado. |
| P03 | No catálogo global, quando um banco de dados não possuir o atributo `"projects"` definido, ele deve ser considerado visível para **todos** os projetos ou para **nenhum** até que seja vinculado explicitamente? | Determina se bancos legados ou gerais poluem a lista de bancos dos projetos ou ficam ocultos na filtragem de contexto. | [RESPONDIDA] | 16/10/2026 | Considerar como banco global/compartilhado, ficando visível e acessível para todos os projetos do ambiente. |
| P04 | Para investigações pontuais de outros projetos, a busca por alias deve aceitar correspondência parcial (ex: digitar apenas `auditoria` para selecionar `erp_auditoria`)? | Facilita a usabilidade do desenvolvedor ao digitar comandos no chat com o agente. | [RESPONDIDA] | 16/10/2026 | Sim, permitir resolução inteligente de alias por correspondência exata prioritária e por substring / tag como fallback. |
| P05 | Quando o usuário indicar diretamente o banco na sua solicitação (ex: "investigar bug no banco de auditoria"), como o assistente/MCP deve se comportar? | Evita fricção desnecessária e perguntas redundantes quando a intenção do usuário já foi explicitada no prompt. | [RESPONDIDA] | 16/10/2026 | Direcionar a operação imediatamente para o banco indicado (via `db_alias` ou ativando com `fb_use_database`), sem fazer perguntas de confirmação. A pergunta só deve ocorrer se a consulta for genérica e o banco não tiver sido indicado. |
